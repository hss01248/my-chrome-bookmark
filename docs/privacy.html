书签墙（Bookmark Wall）隐私政策

生效日期：2026-08-06 · 产品：Chrome 扩展「书签墙」

「书签墙」用于在本地以 Tab + Grid 方式浏览您的 Chrome 书签栏。我们重视您的隐私。本扩展不会收集、出售或向第三方上传您的书签内容。

1. 我们读取哪些数据

  • 书签数据：通过 Chrome 的 bookmarks 权限读取书签栏文件夹与链接（标题、URL、层级），仅用于在扩展页面中展示与搜索。
  • 网站图标：通过 favicon 权限获取书签对应站点的图标，用于卡片显示。

2. 数据如何处理与存储

  • 书签数据仅在您的浏览器本地读取与渲染。
  • 本扩展不将书签标题、URL 或其他内容发送到开发者自有服务器。
  • 本扩展不使用分析 SDK、广告 SDK，也不嵌入第三方追踪脚本。
  • 本扩展当前不使用 storage 持久化您的书签内容（除浏览器本身的书签存储外）。

3. 权限说明

  • bookmarks：读取书签树以展示 Tab / Group / 书签网格，并在书签变更时刷新页面。
  • favicon：加载书签站点的 favicon，提升识别效率。

4. 数据分享

我们不会向广告商、数据经纪商或其他第三方出售或分享您的书签数据。

5. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会故意收集儿童的个人信息。

6. 政策变更

若隐私实践发生变化，我们将更新本页面并调整「生效日期」。重大变更时，建议重新查看本政策。

7. 联系方式

如有隐私相关问题，请通过 GitHub 仓库联系开发者： https://github.com/hss01248/my-chrome-bookmark （可提 Issue）。
